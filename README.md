# Projet de Génie Logiciel – Session normale Summer 2026

Plateforme e-commerce réalisée par 5 groupes. Chaque groupe est responsable d'un module et intervient sur tout le cycle de vie logiciel : analyse des besoins, conception, développement, tests et documentation.

## Les groupes

| Groupe | Thème | Dossier |
|--------|-------|---------|
| 1 | Gestion des utilisateurs, authentification et sécurité | [Groupe-1](./Groupe-1) |
| 2 | Catalogue produits et gestion des stocks | [Groupe-2](./Groupe-2) |
| 3 | Panier, commandes et livraison | [Groupe-3](./Groupe-3) |
| 4 | Frontend, expérience utilisateur et interface d'administration | [Groupe-4](./Groupe-4) |
| 5 | Infrastructure, DevOps, qualité et tests globaux | [Groupe-5](./Groupe-5) |

## Règles de dépôt

- Chaque groupe travaille uniquement dans son dossier `Groupe-N`.
- Chaque dossier contient : `README.md`, `docs/`, `src/`, `tests/`.
- Messages de commit clairs et commits fréquents.
- Qualité, sécurité et traçabilité sont exigées à toutes les étapes.
